RhemaFlow-D v0.801.2 — 5 Design Options

Five UI/UX directions for the operator command centre & congregation stage, evaluated as a senior UI/UX designer would: against a dimmed media booth, a projector, and a 10-second "what's happening?" test.

Option A — "Cathedral Dark" SHIPPED IN v0.801

Near-black blue-grey app, one gold accent reserved for "live / on stage", warm-white serif on pure black for the congregation stage.

  • Operator: three-zone layout — transcript (left), stage preview + scripture index (centre), review queue (right); everything decided in one screen with zero scrolling.
  • Stage: auto-fitting serif type, gold reference badge, 350 ms fade-in — reverent on a projector, readable at the back of the room.
  • Semantics: gold = live/automation; red = needs you; green = healthy. The eye learns the map in one service.

Why it wins: the gold accent carries exactly one meaning (automation is working), so a volunteer operator can trust the room at a glance; dark UI disappears in a dim booth; serif-on-black looks like Scripture, not a dashboard.

Option B — "Broadcast Console"

Pro-AV aesthetic · slate greys · dense tiles
  • Everything-as-tiles, VU meters, tiny caps labels, hardware-like knobs for gain and confidence.
  • Fits the AV team's muscle memory from mixing desks.

Rejected: optimised for engineers, not volunteers; density raises cognitive load during a live service, and it "looks expensive to learn" in front of a church committee.

Option C — "Chapel Light"

Bright parchment · navy & white · print-like
  • Light theme, serif everywhere, feels like a bulletin/missal.
  • Beautiful for screenshots and very churchy.

Rejected: a bright window in a dark booth glares; projectors pair badly with light UI bleed; light themes also invite colourful branding that competes with the verse on screen.

Option D — "Minimal Auto"

One button · nothing else · maximum automation
  • A single Start button and a stage window; the operator is told to trust it.
  • Maximally simple onboarding.

Rejected: violates the PRD's core promise — human control always. When recognition errs once, the operator has no levers, and trust dies mid-service.

Option E — "Mission Control"

Timeline-first · graph-heavy · analytics forward
  • Sermon timeline, confidence graphs, event streams as first-class citizens.
  • Impressive demos; great for post-service review.

Partially adopted: the timeline/index live in the centre panel, but analytics never crowd the live path. Analysis is for after the service, not during it.
